TANUT JUNSRI - TUTORIAL #2

เว็บไซต์ Resume แบบ Static 4 หน้า
1. index.html       = Home
2. experience.html  = Experience
3. projects.html    = Projects
4. contact.html     = Contact

ไฟล์ร่วม: style.css, script.js
รูปภาพอยู่ใน images/

วิธีใช้:
- เปิด index.html เพื่อดูเว็บไซต์ในเครื่อง
- อัปโหลดไฟล์ทั้งหมดภายในโฟลเดอร์นี้ขึ้น GitHub repository
- ต้องให้ index.html อยู่ที่ระดับบนสุดของ repository
- เปิด Settings > Pages > Deploy from a branch > main > / (root)

หมายเหตุ:
ข้อมูลส่วนบุคคลตามที่เจ้าของเว็บไซต์ให้มา
เว็บไซต์จัดทำด้วย HTML/CSS และ JavaScript โดยไม่ใช้ Bootstrap หรือ Tailwind
